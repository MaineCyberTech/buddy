# Buddy Roadmap

## v0.1 — Local-first MVP (Current)

Core virtual pet experience running entirely in the browser.

- [x] PWA shell (manifest, SW, offline support)
- [x] 50 species + 5 tiers + shiny
- [x] 22 personalities + idle messages
- [x] 7 care actions with 6 need stats
- [x] 10 adventure locations with loot
- [x] 45 items + inventory + coin economy
- [x] Lifecycle (Egg → Elder)
- [x] 15 achievements
- [x] Home customization (6 slots, 14 decor items)
- [x] Local auth (guest or account)
- [x] IndexedDB persistence + export/import
- [x] 160+ passing tests

## v0.2 — Cloud & Social (Planned)

- [ ] Supabase auth + cloud save sync
- [ ] Buddy trading / gifting
- [ ] Leaderboards (bond level, collection)
- [ ] Friend visits to homes

## v0.3 — Mini-games & Events

- [ ] 3 mini-games (memory match, reaction test, rhythm)

- [ ] Photo album (screenshots of buddy moments)

## v0.5 — Sound & Animation
