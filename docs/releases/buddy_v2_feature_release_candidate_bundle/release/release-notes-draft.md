# Buddy V2 Release Notes Draft

## Summary

Buddy V2 introduces a full-featured virtual pet platform with deterministic ASCII-art pets, LCD-inspired UI, offline-first play, adventures, loot, lifecycle progression, customization, mini-games, collections, seasonal systems, and release-candidate hardening.

## Highlights

- Hatch a deterministic Buddy generated from user or guest identity.
- Discover species, rarity tiers, and shiny variants.
- Care for Buddy through feed, play, wash, rest, talk, train, and heal actions.
- Explore locations and complete adventures.
- Collect loot, customize the home, and progress through lifecycle stages.
- Play offline with local-first save support.
- Use account-gated progression for persistent advanced features.
- Extra systems include breeding, marketplace, save slots, photo capture, high scores, and sound.
