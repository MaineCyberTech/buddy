# Prompt — Buddy V2 Post-Release Monitoring Agent

After release or preview deployment, inspect available logs, error reports, test output, and user-reported issues.

## Mission

Create a post-release status report and identify rollback-worthy issues.

## Required Report

```txt
docs/buddy/reports/release/buddy-v2-post-release-report.md
```

Include:

- deployment target
- version/tag
- observed errors
- save/load issues
- auth issues
- marketplace/economy anomalies
- PWA/offline failures
- performance issues
- P0/P1/P2/P3 findings
- recommendation: continue, hotfix, or rollback
