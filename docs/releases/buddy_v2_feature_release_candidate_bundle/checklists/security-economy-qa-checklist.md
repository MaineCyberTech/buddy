# Security and Economy QA Checklist

- [ ] Client cannot create negative currency.
- [ ] Client cannot use missing inventory item.
- [ ] Repeated clicks do not duplicate rewards.
- [ ] Save import validates schema.
- [ ] Invalid save does not crash app.
- [ ] High scores validate values.
- [ ] Marketplace purchase validates funds.
- [ ] Marketplace sale validates ownership.
- [ ] Breeding validates inputs.
- [ ] Account-owned records enforce ownership if backend is enabled.
- [ ] No secrets exposed client-side.
