# Security Checklist

- [ ] No secrets in git.
- [ ] Terraform state ignored/protected.
- [ ] Tokens least privilege.
- [ ] SSH restricted.
- [ ] Only required ports exposed.
- [ ] Traefik dashboard protected.
- [ ] cloudflared tunnel token protected.
- [ ] GitHub prod environment protected.
- [ ] Dev/prod state separated.
- [ ] Rollback documented.
