# Provider Source Notes

These notes summarize external provider capabilities that this pack is designed around. Verify against current provider docs before applying.

- Cloudflare documents Terraform provider usage for managing Cloudflare configuration as infrastructure as code.
- Cloudflare Tunnel allows origin servers, APIs, and services to connect to Cloudflare through outbound-only connections without requiring public origin IPs.
- Cloudflare Tunnel Terraform docs describe API token permissions for Tunnel, Access policies, and DNS editing.
- DigitalOcean Terraform documentation describes reserved IP resources that can be mapped to Droplets.

This source notes file is intentionally descriptive only. The implementation agent must inspect current docs and the actual repo before applying changes.
