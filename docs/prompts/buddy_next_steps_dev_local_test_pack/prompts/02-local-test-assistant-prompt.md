# Prompt — Local Browser Test Assistant

You are helping validate the Buddy local MVP in the browser.

## Mission

Guide and assist the operator through running the app locally, testing the Buddy route, and recording results.

## Steps

1. Inspect package manager and scripts.
2. Run install if needed.
3. Run lint/typecheck/test/build.
4. Start dev server.
5. Identify the local browser URL from terminal output.
6. Test app route, hatch flow, care loop, save persistence, guest gating, PWA/offline status, mobile responsiveness, and accessibility.
7. Record results.
