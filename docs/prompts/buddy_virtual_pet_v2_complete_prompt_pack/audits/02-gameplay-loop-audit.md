# 02 Gameplay Loop Audit

## Mission

Audit care loop, need decay, actions, lifecycle, skills, home customization, economy, adventures, and balance.

## Required Output

```md
# Audit Report

## Summary
## Files Inspected
## P0 Findings
## P1 Findings
## P2 Findings
## P3 Findings
## Evidence
## Remediation Plan
## Acceptance Criteria
## Verification Commands
```

## Severity Rules

- P0: release blocker/security/data-loss/build-breaking.
- P1: critical quality or player-impacting issue.
- P2: important but not blocking.
- P3: polish or enhancement.

## Instruction

Inspect actual repo files. Do not guess. Cite file paths and exact observed issues.
