# ASCII Sprite Engine Spec

Sprites are composed from species template + life stage + eyes + mouth + hat + mood pose + shiny overlay.

## Rules
- Monospace rendering only.
- Keep width mobile-readable.
- Prefer 3–7 lines for main Buddy sprites.
- Allow larger profile sprites.
- Hats/accessories are overlays.
- Shiny adds sparkle glyphs and CSS glow.
- Mood changes eyes/mouth/pose.
- Provide accessible text description for every sprite.

## Required Frames
- idle
- happy
- hungry
- dirty
- sleepy
- sick
- shiny idle
- hatch crack frames
