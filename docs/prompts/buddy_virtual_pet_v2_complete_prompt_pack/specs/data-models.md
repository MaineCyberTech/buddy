# Data Models

Core models include `BuddyIdentity`, `BuddyState`, `BuddyStats`, `BuddyNeeds`, `BuddySkill`, `InventoryState`, `HomeState`, `GameSave`, `LocationDefinition`, `LootItem`, `Achievement`, `AdventureResult`, and `CloudSaveEnvelope`.

All persisted models must be versioned and schema-validated.
