# Product Requirements

Buddy is a virtual pet PWA where every user hatches a deterministic ASCII-art companion. The game prioritizes charm, collection, short daily sessions, offline play, and long-term care progression.

## Personas
- Casual mobile player: wants quick care sessions.
- Collector: wants rare species, shiny variants, hats, decor, trinkets.
- Progression player: wants lifecycle, skills, achievements, adventures.
- Offline-first user: wants installable play without constant connection.

## Primary Loops
- 30–90 second care loop.
- 5–10 minute adventure/customization loop.
- Weekly/monthly collection and evolution loop.

## Monetization Constraint
No real-money purchases in this pack. Avoid dark patterns and predatory FOMO.
